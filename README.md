# Chronicle

Chronicle is a deterministic social-and-ecological simulation core.

The implementation, configuration, tests, and operational notes live in [`sim-core/`](sim-core/). Start with [`sim-core/README_RUN.md`](sim-core/README_RUN.md) for how to run and validate the simulator.

## Repository policy

This repository tracks source code, configuration, tests, and design/implementation notes. Generated simulation runs, checkpoints, test output, Python bytecode, and historical ZIP handoff archives are intentionally ignored.
